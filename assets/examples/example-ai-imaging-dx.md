# 示例：AI肺结节影像辅助诊断软件 · 中国NMPA注册分析

> 这是一个完整的Skill输出示例，展示医疗AI专用Skill怎么回答问题。

---

## 输入信息

| 项 | 内容 |
|---|------|
| 产品名称 | AI肺结节CT影像辅助诊断软件 |
| 产品描述 | 独立软件，部署在医院PACS系统，自动分析胸部CT，标记肺结节，给出良恶性建议 |
| 预期用途 | 辅助放射科医生检测肺结节，给出恶性概率参考，最终诊断由医生做 |
| 目标用户 | 放射科医生 |
| 目标市场 | 中国NMPA |
| 数据来源 | 三家三甲医院的胸部CT数据，共10万例 |
| 算法类型 | 深度学习CNN，模型每季度更新一次 |

---

## Skill输出

### 一、SaMD分类判定

| 项 | 结论 |
|---|------|
| 医疗情况 | 严重（肺癌，致死性） |
| 决策影响 | 临床管理（辅助诊断，不是直接治疗） |
| **SaMD等级** | **III级** |
| **中国注册路径** | **三类医疗器械注册** |
| 分类依据 | 《人工智能医疗器械注册审查指导原则》、《医疗器械分类目录》 |
| 置信度 | 确定 |

### 二、注册路径建议

- **分类**：三类医疗器械
- **路径**：国家药监局医疗器械技术审评中心（器审中心）注册
- **审批类型**：创新医疗器械特别审批（如符合条件可申请）
- **周期**：12-24个月（含临床试验）
- **临床要求**：必须做前瞻性临床试验（通常要求多中心、数千例）

### 三、AI特殊文档清单（和普通器械不一样的地方）

#### 🔴 P0级必交：

| 文档 | 要点 |
|------|------|
| **GMLP合规报告** | 数据质量、训练过程、质控、团队 |
| **PCCP预定变更控制计划** | 算法每季度更新，必须在PCCP里写清楚 |
| **算法描述文档** | 模型架构、训练方法、超参数、版本管理 |
| **数据集说明** | 训练集/验证集/测试集来源、分布、标注 |
| **数据集偏倚分析** | 年龄、性别、地域、设备型号亚组分析 |
| **算法性能报告** | 灵敏度、特异度、AUC、置信区间 |
| **多中心临床试验报告** | 前瞻性、多中心、和医生阅片对比 |
| **软件描述文档** | 按照《医疗器械软件注册审查指导原则》 |
| **网络安全研究报告** | 数据安全、隐私保护、防攻击 |

#### 🟡 P1级建议交：

| 文档 | 要点 |
|------|------|
| 可解释性分析 | 热图/注意力图，说明AI关注哪些区域 |
| 人机交互设计 | 人工复核流程、医生可以修改AI结果 |
| 真实世界研究计划 | 上市后持续收集数据 |

### 四、PCCP核心要点（算法每季度更新）

因为算法要每季度更新，PCCP必须写清楚：

| 允许的变更 | 不允许的变更 |
|-----------|-------------|
| 用新数据再训练模型 | 改变预期用途（从辅助诊断变成自动诊断） |
| 调整性能阈值 | 扩展到其他疾病（比如肺结核） |
| 优化模型架构 | 改变输入类型（从CT扩展到X光） |
| 提升性能 | 去掉人工复核步骤 |
| 修复已知问题 | 降低安全要求 |

每次更新后：
- 必须在独立测试集上验证
- 性能指标不能低于基线
- 必须有回滚机制
- 重大变更需要向NMPA报告

### 五、临床试验要求

- **试验类型**：前瞻性、多中心、随机对照/平行对照
- **对照方法**：医生单独阅片 vs AI辅助阅片
- **样本量**：通常需要数千例（按统计学计算）
- **中心数**：至少3-5家不同层级医院
- **主要终点**：灵敏度、特异度、AUC
- **次要终点**：阅片时间、医生信心、漏诊率
- **随访**：恶性结节要病理确认，良性结节要随访

### 六、发补高风险点预警

| 风险点 | 为什么容易被发补 |
|--------|---------------|
| 🔴 数据集偏倚 | 只在三家医院数据训练，没有覆盖基层医院/不同设备 |
| 🔴 测试集数据泄露 | 测试集和训练集有同一位患者的病例 |
| 🔴 多中心试验设计 | 样本量不够、中心数不够、对照设计不合理 |
| 🔴 PCCP写得太泛 | 只说"会持续优化"，没说清楚变更范围和验证方法 |
| 🟡 可解释性不足 | 只给结果，没有热图/依据 |
| 🟡 人工复核 | 没有明确说明医生可以修改AI结果 |

### 七、周期与费用估算

| 阶段 | 周期 | 说明 |
|------|------|------|
| 数据准备 | 3-6个月 | 数据收集、标注、清洗 |
| 算法开发 | 3-6个月 | 模型训练、验证 |
| 临床试验 | 12-18个月 | 伦理、入组、随访、分析 |
| 注册申报 | 12-18个月 | 受理、发补、审批 |
| **总计** | **2-4年** | 从开始到拿证 |

| 费用项 | 大致范围 |
|--------|---------|
| 数据标注 | 数十万 |
| 临床试验 | 数百万 |
| 注册代理 | 数十万 |
| 检验检测 | 数十万 |
| **总计** | **数百万到千万级** |

## 示例总结

这就是医疗AI Skill和普通注册Skill的区别：
- 普通注册Skill只告诉你"三类注册"
- 医疗AI Skill还告诉你：
  - GMLP要做什么
  - PCCP怎么写
  - 数据集偏倚怎么分析
  - 临床试验特殊要求是什么
  - 发补最容易踩什么坑

这些是普通通用Skill覆盖不了的。
