## 为什么单独做一个AI Skill？

医疗AI注册和普通器械**完全不一样**：
- 有特殊的分类框架（IMDRF SaMD分级）
- 有特殊的文档要求（GMLP、PCCP）
- 有特殊的临床验证要求（算法性能数据集）
- 有特殊的变更管理（算法更新要不要重新注册？）

普通注册Skill覆盖不了这些特殊要求。

---

## 这个Skill帮你做什么？

输入：你的AI软件是干什么的、给谁用、风险多大
输出：
1. SaMD分类判定（I/II/III/IV级）
2. 注册路径建议
3. AI特殊文档清单：GMLP、PCCP、算法描述、数据集说明
4. 发补高风险点预警
