# GMLP + PCCP 自查清单 · 医疗AI注册必备

> 医疗AI和普通器械注册最大的区别：要多做GMLP和PCCP这两个东西。

---

## 一、GMLP（良好机器学习实践）自查清单

GMLP（Good Machine Learning Practice）是FDA和英国MHRA、加拿大Health Canada联合发布的AI/ML医疗器械开发指南。

### 🔴 P0级（必须有）

| # | 要求 | 自查要点 |
|---|------|---------|
| 1 | 多学科团队 | 团队里有软件工程师、临床医生、质量人员 |
| 2 | 数据质量 | 训练数据来源清晰、标注规范、有质控 |
| 3 | 数据集代表性 | 训练集覆盖目标人群，没有选择偏倚 |
| 4 | 偏倚分析 | 做了人群亚组分析（年龄、性别、种族等） |
| 5 | 训练集/测试集隔离 | 测试集和训练集没有重叠 |
| 6 | 算法性能 | 灵敏度/特异度/AUC等指标有统计分析 |
| 7 | 人工复核 | 有人在回路（HITL），AI不是全自动决策 |
| 8 | 可解释性 | 算法结果有一定的可解释性（不是黑箱） |
| 9 | 网络安全 | 有网络安全设计，防止数据泄露/篡改 |
| 10 | 部署后监控 | 有计划监控算法上线后的性能变化 |

## 二、PCCP（预定变更控制计划）自查清单

PCCP（Predetermined Change Control Plan）是FDA批准的——有了PCCP，你可以在不重新注册的情况下更新算法，只要在PCCP约定的范围内。

### 🔴 P0级（PCCP必须写清楚的）

| # | 部分 | 要写什么 |
|---|------|---------|
| 1 | 变更描述 | 算法可以做哪些变更？（再训练、调阈值、新增功能） |
| 2 | 变更范围 | 什么可以改？什么不能改？（预期用途不能改） |
| 3 | 验证方法 | 每次变更后怎么验证性能？ |
| 4 | 数据管理 | 新数据怎么收集、标注、质控？ |
| 5 | 性能阈值 | 性能指标低于多少不能上线？ |
| 6 | 回滚机制 | 新版本有问题，怎么快速回滚？ |
| 7 | 版本管理 | 版本号怎么编，怎么追踪？ |
| 8 | 变更通知 | 哪些变更要通知FDA？哪些不用？ |

### PCCP不允许做的变更

- ❌ 改变预期用途（比如从"辅助诊断"变成"自动诊断"）
- ❌ 改变目标人群（比如从成人扩展到儿童）
- ❌ 改变输入类型（比如从X光扩展到CT）
- ❌ 降低安全性（比如去掉人工复核步骤）

## 三、常见发补高风险点

| 高风险点 | 为什么会被发补 |
|---------|---------------|
| 数据集偏倚没分析 | 只在一家医院的数据上训练，没有外部验证 |
| 测试集和训练集重叠 | 测试集是从训练集里随机抽的，数据泄露 |
| 性能指标只报AUC | 还要报灵敏度、特异度、置信区间 |
| PCCP写得太泛 | 说"会持续优化"，但没说清楚具体怎么改 |
| 没有人工复核 | 想做全自动决策，没有医生在回路 |
| 可解释性不足 | 完全黑箱，说不清楚为什么出这个结果 |

## 四、中美欧三地AI要求对比

| 要求 | 美国FDA | 中国NMPA | 欧盟MDR |
|------|---------|---------|---------|
| GMLP | 有，AI/ML Action Plan | 有，AI器械审评指导原则 | 有，MDCG AI指南 |
| PCCP | 有，2023年开始 | 有，2024年指导原则 | 正在制定中 |
| 数据集偏倚 | 强制分析 | 强制分析 | 强制分析 |
| 外部验证 | 强烈建议 | 强制（多中心） | 强烈建议 |
| 人工复核 | 视风险等级 | 强制（III类） | 视风险等级 |
