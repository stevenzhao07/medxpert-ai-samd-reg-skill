# SaMD分类判定 · IMDRF框架

> 输入：AI软件的用途 + 医疗情况 → 输出：SaMD等级（I/II/III/IV）

---

## 什么是SaMD？

Software as a Medical Device（软件即医疗器械）：
- **独立运行**的软件，不是硬件内置的
- **用于医疗目的**：诊断、治疗、监测、预测
- 例子：影像AI辅助诊断、心电AI分析、病历辅助生成

---

## IMDRF分类矩阵

SaMD按两个维度分级：

### 维度1：医疗情况（Medical Condition）

| 等级 | 说明 |
|------|------|
| **A** | 非严重情况（Non-serious） |
| **B** | 严重情况（Serious） |
| **C** | 危急情况（Critical） |

### 维度2：决策影响（State of Healthcare Situation）

| 等级 | 说明 |
|------|------|
| **1** | 驱动临床管理（Treat & Manage） |
| **2** | 驱动治疗驱动（Drive Clinical Management） |

---

## 分类结果矩阵

| | A 非严重 | B 严重 | C 危急 |
|---|---|---|---|
| **1 临床管理** | SaMD I | SaMD II | SaMD III |
| **2 治疗驱动** | SaMD II | SaMD III | SaMD IV |

---

## 各等级对应注册路径

| SaMD等级 | 美国FDA | 欧盟MDR | 中国NMPA |
|----------|---------|---------|----------|
| I | Class I 一般控制 | Class I | 一类备案 |
| II | Class II 510(k) | Class IIa | 二类注册 |
| III | Class II 510(k) / De Novo | Class IIb | 三类注册 |
| IV | Class III PMA | Class III | 三类注册 |
